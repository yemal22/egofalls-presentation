# Audience game clip sources

Source dataset: https://www.kaggle.com/datasets/vundle/egofalls-v2
Authors' original project: https://github.com/Xueyi-Wang/EGOFALLS
Kaggle mirror license: CC0 (as documented in the project's existing examples).

These are staged activities, not accidental falls or model predictions.
All four selected source clips are S_FI / Indoor / Neck.
Video and original audio are retained for the full clip. H.264 at 640 pixels wide / 24fps, AAC 64kbps; metadata stripped for neutral presentation.
The exercise records one presenter-entered group choice; it is not a controlled human-performance evaluation.
